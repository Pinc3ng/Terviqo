# Terviqo
Terviqo adalah platform kolaborasi tim yang dirancang untuk membantu tim mengelola file proyek, berbagi catatan, dan melindungi informasi sensitif menggunakan kriptografi. Platform ini bertujuan menyediakan lingkungan kerja yang terorganisasi dengan fitur penyimpanan file terenkripsi, verifikasi integritas file, dan kontrol akses.
